# Glossário de cloud para o financeiro

Termos usados no relatório, explicados sem jargão técnico.

| Termo | O que significa na prática |
|---|---|
| **Cloud (nuvem)** | Alugar servidores, armazenamento e software de um provedor (AWS), em vez de comprar e manter equipamentos próprios. |
| **On-premises** | Infraestrutura própria, instalada dentro da empresa. É a situação atual da Abstergo. |
| **CAPEX** | Investimento em bens (comprar servidores). Gasto alto, antecipado e que deprecia. |
| **OPEX** | Despesa operacional recorrente. Na nuvem, a empresa paga mensalmente pelo que usou. |
| **Pay-as-you-go** | Pagamento conforme o uso, como a conta de luz: consumiu mais, paga mais; consumiu menos, paga menos. |
| **Instância EC2** | Um servidor virtual alugado na AWS. Pode ser ligado, desligado e redimensionado em minutos. |
| **Auto Scaling** | Recurso que aumenta ou diminui automaticamente o número de servidores conforme a demanda. |
| **Savings Plans / Instâncias Reservadas** | Desconto oferecido pela AWS quando a empresa se compromete a usar uma quantidade mínima por 1 ou 3 anos. |
| **Bucket S3** | Uma "pasta" na nuvem para guardar arquivos, com cópias automáticas que protegem contra perda. |
| **S3 Glacier** | Faixa de armazenamento muito barata para arquivos que quase nunca são consultados (arquivo morto digital). |
| **Ciclo de vida (lifecycle)** | Regra que move arquivos automaticamente para faixas mais baratas depois de um tempo. |
| **Serverless / Lambda** | Código que roda só quando é acionado; a empresa paga apenas pelos milissegundos de execução. |
| **Camada gratuita (Free Tier)** | Cota mensal de uso que a AWS oferece sem cobrança em vários serviços. |
| **Cost Explorer** | Painel que mostra quanto foi gasto em cada serviço, mês a mês. |
| **AWS Budgets** | Define um orçamento e envia alerta por e-mail quando o gasto se aproxima do limite. |
| **FinOps** | Prática de gestão financeira da nuvem: unir TI e financeiro para gastar só o necessário. |
